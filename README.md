# psicologa-roangela-site-astro-cflare

Site Astro estático. Deploy: ver `deploy-cloudflare.bat` e a skill `.cursor/skills/astro-cloudflare-git/SKILL.md` (build `npm run build`, saída `dist`, painel Cloudflare).

Após cada deploy, validar performance no [PageSpeed Insights](https://pagespeed.web.dev/) (mobile e desktop) na URL que estiveres a usar (ex.: pré-visualização `https://psicorr2025.alukser.workers.dev/` — o relatório usa a URL sem `#fragmento`). A skill inclui checklist e prioridades típicas face ao código.
